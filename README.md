# FINAL-YEAR-PROJECT
Overview of the Website: The NancyFitness website is designed to promote a fitness gym, offering information about the gym, its pricing, services, and subscription plans. The site is structured into several sections for easy navigation:  Header Section: Contains the gym's logo, navigation menu, and a call-to-action button for users.
NancyFitness is a responsive and modern website designed for a fitness gym, offering information about the gym, its pricing, services, and subscription plans. It includes a countdown timer, pricing tables, and a section comparing the available plans.
Responsive Design: The website adapts to different screen sizes for mobile, tablet, and desktop.

Countdown Timer: Displays a countdown for the ongoing promotion, creating urgency for visitors.

Pricing and Subscription Plans: Displays three different subscription plans (Free, Pro, Enterprise) with the ability to compare the plans side by side.

Interactive Elements: Buttons with hover effects to increase user engagement.

Clean, User-Friendly Layout: The website is organized with clear sections and visually appealing design elements.
HTML: For structuring the content.

CSS: For styling the website with Flexbox, responsive design, and interactive elements.

JavaScript: To implement the countdown timer functionality.

Responsive Design: Using media queries and Flexbox to make the website mobile-friendly.
